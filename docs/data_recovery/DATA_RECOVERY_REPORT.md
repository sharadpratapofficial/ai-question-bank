## F. Which IDs are reliable?

- **QBG ids: HIGH.** They have a strict format and are cross-verified:
  - the embedded link id equals the row id in 14,186/14,186 rows
  - the PYQ hyperlink equals the cell in 2,578/2,578 cells
- **44 test positions have no usable id.** They hold `Paper-02` ×43 or `QUE ERROR` ×1 and are listed in `low_confidence_records.csv`.
- **The brief's example id `m17hp8zu9zycqk5ripht6kf9ew` does not exist.** It splices two real ids (see IDENTIFIER_FORENSICS.md).
- **The docx is deliberately unlinked.** The sheet's 15-12-2024 AITS test is a class-11 paper; the docx is class-12. Its PYQ citations narrow 52 questions to a 30-id candidate set each (LOW).

## H. What duplicates exist?

- **Translation duplicates cannot be assessed:** no Hindi content exists locally, and RTS Hindi is a tracker only.
