# PW AI Hackathon Demo Script

## Demo title

PW Question Bank AI

## Demo link

[https://aiquestionbank.netlify.app](https://aiquestionbank.netlify.app)

## Suggested demo length

3 to 5 minutes

## Demo goal

Show that the product solves real academic workflow pain for coaching institutes by using AI to reduce manual effort in:

- PDF import
- question verification
- translation
- question generation
- test creation
- full-paper quality analysis

## 1. Opening

Hello, this is PW Question Bank AI, built for the PW AI Hackathon.

This product helps coaching teams convert raw academic content into a structured question bank, verify questions with AI, generate new practice material, create tests, and run full-paper quality checks before papers reach students.

## 2. Show the upload flow

Navigate to the upload flow.

Say:

Here a content team can upload a question PDF and a solution PDF. Instead of manually typing every question into a database, AI extracts the questions, options, answers, solutions, and metadata in a structured format.

Show:

- uploaded file flow
- extracted question preview
- review before save

Key impact line:

This removes one of the biggest academic operations bottlenecks, which is converting static PDFs into a reusable question bank.

## 3. Show question bank and AI verification

Navigate to the questions area.

Say:

Once questions are saved, users can search and filter them by subject, chapter, topic, question type, difficulty, and source.

Open one question and show:

- edit view
- AI verify
- AI solution
- AI suggestion
- AI verified tagging

Key impact line:

This reduces repetitive faculty review time by giving a first-pass AI check on answer correctness and solution quality.

## 4. Show translation / vernacular support

Show translation in the question flow or AI tools flow.

Say:

The same content can also be translated into vernacular-ready academic versions, which is very useful for serving a broader student base in the language they learn best.

Key impact line:

This makes multilingual academic delivery much faster than rewriting content manually.

## 5. Show AI question generation

Navigate to AI generation.

Say:

If a content team needs fresh practice questions for a chapter, topic, or difficulty level, they can generate them directly with AI and review them before use.

Key impact line:

This helps fill question-bank gaps quickly and accelerates worksheet and test preparation.

## 6. Show test generation

Navigate to the tests module.

Say:

Here users can create tests by exam type, subject mix, chapter selection, question type, and difficulty distribution.

Show:

- test creation flow
- preview
- export-ready output

Key impact line:

This makes paper creation more consistent and much less manual for coaching teams handling many batches.

## 7. Show full test verification

From the preview flow, run or show the Verify Test Using AI feature.

Say:

This is one of the strongest features. The system can verify the entire paper, solve questions, flag suspicious answers, check pattern compliance, inspect syllabus balance, and create a full paper-level quality report.

Show:

- provider/model selection
- question-level AI verified status
- report summary

Key impact line:

Instead of doing only question-level checks, we are doing a quality review of the complete academic paper.

## 8. Show analytics

Navigate to analytics.

Say:

The analytics dashboard shows overall question-bank health, metadata completeness, subject coverage, difficulty mix, usage patterns, and content gaps. This helps academic heads decide what to create, clean up, or rebalance next.

Key impact line:

This turns academic content planning from guesswork into a data-driven workflow.

## 9. Close

PW Question Bank AI reduces manual academic operations across the full content lifecycle, from PDF import to final paper quality control. For coaching institutes, that means faster turnaround, better paper quality, stronger reuse of institutional content, and measurable time savings.

Thank you.
