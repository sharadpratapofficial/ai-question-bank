# data/ (generated)

This whole folder is regenerated by `node scripts/data/recovery/run_all.mjs`. The pipeline documentation is in `docs/data_recovery/README.md`.
It is git-ignored because it is ~200 MB and derived from proprietary workbooks.

- `raw/`: the only place a human puts files. All of these are optional and read-only to the pipeline (see `docs/data_recovery/SOURCE_INTAKE.md`):
  - `raw/qbg/`: an authorized QBG export (CSV / JSON / JSONL)
  - `raw/documents/`: authorized DOCX/PDF source documents, named by file name or Drive id
  - `raw/rankup/`: RankUp registers and generated bank
  - `raw/other/`: other backups (inventoried only)
- `staging/`, `extracted/`, `canonical/`, `reports/`, `review/`: pipeline outputs
- `import_plans/`, `import_logs/`, `import_state/`: import-script work files (dry-run plans)
