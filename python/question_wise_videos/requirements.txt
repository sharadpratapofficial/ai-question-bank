#                 (installs to "C:\Program Files\Tesseract-OCR\tesseract.exe",
#                 auto-detected — or set TESSERACT_CMD to override).
#                 Linux: apt install tesseract-ocr. Mac: brew install tesseract.
#                 If tesseract isn't found, detection silently falls back to
#                 the visual-diff method (no numbered-slide requirement).
